The problem

You change a prompt. Tests pass. You ship it. Two days later support notices that answers quietly got worse — dropped fields, truncated replies, refusals — and nobody caught it, because there was no test that could.

Existing eval tools (promptfoo, Langfuse, DeepEval, Braintrust) are good, but they all start from a hand-written golden dataset. llmdiff starts from real production traffic: capture what users actually sent, replay it against the candidate, and compare outputs across independent dimensions.

How it works

  1. Capture — record prompts and outputs from your live system (proxy middleware, SDK wrapper, or import a log).
  2. Replay — send the same prompts to the candidate system (new prompt version, different model, different provider).
  3. Compare — every dimension scores baseline and candidate with the same definition, then derives a verdict per case: win (candidate scored higher), tie (equal within tolerance), loss (regression).

Quickstart

# A corpus is JSONL, one object per line:
# {"id": "c1", "prompt": "...", "baseline_output": "...",
#  "candidate_output": "...", "metadata": {"model": "...", "tags": [...],
#  "timestamp": "2026-11-01T12:00:00Z"}}

llmdiff init                      # scaffold an example corpus
llmdiff compare corpus.jsonl      # verdict matrix to stdout (markdown)
llmdiff compare corpus.jsonl --format json
llmdiff compare corpus.jsonl --format html --output report.html
llmdiff compare corpus.jsonl --dimensions structure,json_valid --tolerance 0.05

# CI regression gate (exit 1 when regressions exceed the budget):
llmdiff compare corpus.jsonl --max-loss-rate 0.05

Features

  • Zero runtime dependencies — pure stdlib; optional extras only for embeddings/judge.
  • Deterministic — same corpus in, same matrix out. No LLM calls unless you enable a judge dimension.
  • 60+ built-in dimensions — text, structure, code, format, safety, QA, numeric, cost.
  • CI-native reporters — markdown, JSON, HTML, JUnit, SARIF, GitHub comment, Slack, CSV, terminal.
  • Capture — proxy middleware, OpenAI/Anthropic SDK wrappers, PII redaction, sampling, dedup.
  • Replay — multi-provider, retry with backoff, response cache, batching, parameter sweeps.
  • Analytics & self-benchmark — significance tests, trends, clustering, anomaly detection, power analysis, and a dogfooded benchmark suite.
  • Extensible — plugins are plain Python classes.
